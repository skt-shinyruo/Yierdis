# 0004: 事务入队只拒绝命令名和参数个数

日期：2026-10-07
状态：Accepted

## 背景

入队时用完整参数解析做校验，会让一条命令的参数、选项或取值不合法立刻失败，并让整笔事务在 EXEC 时作废。这是先前有意保留的全有或全无：与时间无关的解析错误在入队阶段失败，只有依赖墙钟的检查留到执行。

Redis 的入队拒绝更窄。命令不存在或参数个数不对，才会拒绝入队并作废整笔事务。其余错误先进入排队，EXEC 时只有那一条失败，同一笔事务里的其他命令照常执行。

## 决定

对齐 Redis 8.0.2 的入队边界（2026-10-07 分诊 #168）：

- 入队拒绝并作废整笔事务的，只有：未知命令、参数个数不对、事务里禁止出现的命令、队列容量超限。
- 参数内容、选项冲突、取值范围和类型错误都进入队列。EXEC 返回每条命令自己的回复；出错的那一条是错误，其他命令的写入仍然生效。
- 依赖墙钟的过期时间检查继续留在执行时，不因为入队时刻的时钟作废整笔事务。

## 影响

- 现有「入队即报错、EXEC 整笔作废」的测试要改成「已入队，EXEC 里只有那一条失败」。
- 这条不再写成有意保留的已知差异。
